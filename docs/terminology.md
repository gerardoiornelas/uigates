# UI-GATES Terminology

| Term | Canonical meaning |
| --- | --- |
| **UI-GATES** | User-Intent Gated Agentic Task Execution & Synthesis: the complete system. |
| **UI-GATE** | The execution-time authority decision inside UI-GATES. |
| **Compound Engineering** | UI-GATES applied to software engineering. |
| **Principal** | The human who establishes objectives and authorizes risk. |
| **Intent** | A bounded expression of why work may be undertaken. |
| **Knowledge Steward** | The role that maintains trustworthy, reusable project learning. |
| **Receipt** | The provenance record for one authorized action and its verification. |
| **OKF + Graph** | Committed repository knowledge plus generated relationship and retrieval views. |
